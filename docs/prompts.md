# Prompts listos para clase
## A — Entender negocio
"Lee `proyecto/01-contexto.md`, el SOP y EARS del equipo. Hazme cuatro preguntas difíciles sobre usuarios, excepciones, datos y valor del MVP. No escribas código todavía."

## B — Frontend nuevo
"Quiero tres páginas: Inicio, Solicitudes y Bandeja de tareas. Propón un mapa de navegación sin código, qué acción BPMN activa cada botón y qué API se necesita. Muéstrame un esquema y espera aprobación."

## C — ER nuevo
"A partir de nuestras pantallas y EARS, propón entidades, cardinalidades, restricciones, índices y política de privacidad. Distingue entidades locales y variables de Camunda. Dibuja Mermaid ER antes de crear tablas."

## D — Una tarea humana
"Implementa solo Validar áreas en modo mock: tabla y formulario, validación backend, prueba de aceptación, persistencia y correlación con la tarea BPMN. No modifiques otras pantallas."

## E — Docker y cloud
"Ejecuta pruebas, describe los cambios, valida `docker compose config` y construye contenedores. Si el modo mock pasa, propón cómo probar contra Camunda cloud sin escribir secretos en código ni navegador. No despliegues sin confirmación."
