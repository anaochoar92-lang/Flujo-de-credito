# Espacio de trabajo individual
Copia el documento de tu proceso a `01-fuentes/`. Deja los originales intactos.

Después utiliza, en este orden, los comandos de OpenCode:
`/01-analizar` → `/02-entrevistar` → `/03-ears` → `/04-modelar` → `/05-generar` → `/06-auditar` → `/07-corregir`.

No asumas respuestas a preguntas abiertas y versiona todo BPMN corregido en Camunda.

Si modificas un Word ya analizado, guarda el DOCX y usa `/00-actualizar-sop`. El sistema conservará versiones y preguntará qué diferencias deben incorporarse a los modelos. No utilices `/07-corregir` para comenzar desde un DOCX nuevo.
